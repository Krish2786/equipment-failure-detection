# Equipment Failure Detection System (MachineGuard)
> Machine Learning System for Infosys Springboard Internship 7.0 / College Engineering Capstone Project: **"Machine Learning System for Early Detection of Equipment Failure"**

The complete React + Vite application is located in [`equipment-failure-frontend/`](./equipment-failure-frontend/).

## Quick Start
```bash
# Navigate to the frontend directory
cd equipment-failure-frontend

# Install dependencies
npm install

# Start Vite development server
npm run dev
```

Or from this root directory:
```bash
npm --prefix equipment-failure-frontend install
npm run dev
```

For full system architecture, continuous probability paradigm details, and sensor specifications, see [equipment-failure-frontend/README.md](./equipment-failure-frontend/README.md).
